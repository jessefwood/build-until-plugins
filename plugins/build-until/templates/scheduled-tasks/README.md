# Scheduled task templates

The setup wizard offers these one at a time. For each one the student says yes to, their AI brand builder fills in the blanks (in braces) from what it knows, asks for anything missing, and creates the task in the student's own Claude app (Code tab → Scheduled → New task) or with a scheduled task tool if it has one.

| File | When | What |
|---|---|---|
| morning-brief.md | Weekdays 7:00 AM | Today's calendar, what needs you, drafts only |
| ceo-weekly-scorecard.md | Sundays 6:00 PM | The ceo-audit skill |
| cfo-monthly-audit.md | 1st of the month, 9:00 AM | The cfo-audit skill |
| monday-upgrade-check.md | Mondays 8:00 AM | Runs /build-until:update and says what's new |

Every task: reads first, drafts instead of sending, and never touches passwords, keys or payments.
